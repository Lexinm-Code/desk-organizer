# 桌面收纳盒 v1.0.3

一个悬浮的桌面图标收纳盒：**双击桌面空白处**唤出，**鼠标移开自动隐藏**。平时藏在系统托盘右下角，不挡事。

各版本改动见 **[更新日志.md](更新日志.md)**。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🎯 双击桌面唤出 | 全局鼠标钩子，双击桌面空白处（不是图标）就弹出来 |
| ⚡ 边缘唤出 | 把窗口贴到哪条屏幕边，就只认哪条边；游戏全屏时自动安静 |
| 🖱️ 自动隐藏 | 鼠标移开窗口后自动收起 |
| 📌 固定窗口 | 标题栏图钉按钮，固定后常显方便拖图标 |
| 🗂️ 双区分类导航 | 顶部标签 = 你自己的分类；左侧 = 预置类型分类（文档/图片/视频/音乐/程序/压缩包/其他） |
| 🌐 「全部」总览页 | 一个页面看完所有分类的图标，拖进来自动按类型分拣 |
| 🤖 按类型自动归类 | 拖入文件按后缀进已存在分类，绝不擅自新建分类 |
| 🔍 搜索过滤 | 顶部搜索框输入关键字，即时过滤图标 |
| ⭐ 常用置顶 | 打开越多的图标排得越靠前 |
| 🖼️ 图片缩略图 | 图片文件直接显示真实内容，系统图标统一规格化大小（v1.0.3 起按需小尺寸解码 + 图标缓存，重画几乎不花时间） |
| 💬 悬停详情 | 鼠标停在图标上显示文件信息 |
| ↕️ 拖拽排序 | 图标之间拖动换位，落在空白处挪到末尾 |
| 🧲 拖入收纳 | 从桌面拖进来**会从桌面消失**（实际移动文件），右键可恢复原位 |
| 🗑️ 右键删除 | 删除图标进回收站，反手就能恢复 |
| 📐 八方向缩放 | 窗口边缘/四角都能拖，尺寸自动记忆 |
| 🖱️ 标题栏拖动 | 整个窗口任何空白处按住都能拖走 |
| 🎨 五套皮肤 | 深色 / 浅色 / 玻璃 / 青墨 / 暖沙 一键切换 |
| 🔊 音效提示 | 单击/双击/拖入等交互音效，可关 |
| ⚙️ 设置对话框 | 托盘菜单或标题栏⚙️按钮打开，可改窗口大小/图标间距/开机自启 |
| 🖥️ 右键菜单 | 图标上右键：打开 / 打开所在位置 / 查看属性 / 恢复原位 / 删除 |
| 🚀 开机自启 | 设置里勾上，注册表 HKCU\Run 写入，不用管理员权限 |
| ℹ️ 关于此插件 | 托盘菜单查看版本信息与联系方式 |
| ☕ 赞助入口 | 托盘菜单或标题栏☕按钮，支持微信/支付宝 |

## 🚀 使用方法

**打包版用户**：双击 `桌面收纳盒.exe` 即可。

**源码运行**（开发者）：
```bash
pip install PyQt5 pywin32
python 收纳盒.py   # 或双击 启动收纳盒.bat（后台静默运行）
```

## 🛠️ 技术栈

- **Python 3.12**（3.8+ 应该也能跑）
- **PyQt5 5.15.x**（界面）
- **pywin32 312**（Windows API）
- Windows 原生 WH_MOUSE_LL 低级鼠标钩子

## ⚠️ 注意事项

- **bat 必须 GBK + CRLF**（中文文件名在 cmd 下才能正确解析）
- **Windows DPI 缩放**：程序自动声明 DPI 感知，125% / 150% / 200% 正常
- **桌面拖入会真的移动文件**到收纳盒数据目录，不是复制
- **非桌面来源**（开始菜单、下载文件夹）只建快捷方式，不动原文件

## 🧑‍💻 开发笔记

### 关键技术点（踩过的坑）

| 坑 | 解法 |
|---|---|
| PyQt5 槽名必须 ASCII | `connect` 的方法名不能含中文 |
| bat 必须 GBK + CRLF | PowerShell `[IO.File]::WriteAllText(路径, ($行 -join "\`r\`n"), [Text.Encoding]::GetEncoding(936))` |
| deleteLater 不立即删 | `w.setParent(None)` 再 `deleteLater()`，否则旧按钮叠在新按钮上 |
| PyInstaller 打包后路径 | `sys.frozen=True` 时用 `sys.executable` 的父目录（不是 `__file__`） |
| `QIcon` 不接受 `QImage` | 本机 PyQt5 5.15.11 里 `QIcon(QImage)` 直接 TypeError，必须先 `QPixmap.fromImage(img)` 中转 |
| pythonw 静默闪退看不到原因 | 顶层把 `sys.excepthook` 指向 `_记录崩溃`，异常写进 `启动日志.txt`（正常启动 5 秒后自删）；写自检脚本时要记得把 excepthook 换回默认，否则报错被吞 |
| 打包形态选择 | onedir（exe + `_internal/`）比 onefile 启动快近一倍、少一个引导进程：实测 1.41 秒/68.8 MB vs 2.71 秒/78.5 MB |
| 打包后启动命令 | 打包版注册表直接写 `start "" "桌面收纳盒.exe"`，开发版用 `cmd /c start "" "启动收纳盒.bat"` |
